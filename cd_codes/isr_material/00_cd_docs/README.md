# ISR practicals from the assignment documents

Each assignment has its own folder with runnable code, input samples and a quick-start guide. The six original DOCX documents are kept here for comparison.

| Assignment | Folder | Objective |
|---|---|---|
| 1 | `01_Conflation` | Stop-word removal, stemming, lemmatization and term-frequency representation |
| 2 | `02_Single_Pass_Clustering` | TF-IDF and single-pass clustering |
| 3 | `03_Inverted_Index_Whoosh` | Inverted index, Boolean and ranked Whoosh search |
| 4 | `04_IR_Evaluation` | Cranfield-style q1 ranking and retrieval metrics |
| 5 | `05_CBIR` | HSV and GLCM features, ImageHash and CBIR |
| 6 | `06_Weather_Product_Crawler` | Live weather and product crawling |

Open each folder's `README.md` for setup and run steps. Assignment 4 includes a small example in the same folder structure as the document; replace it with the Cranfield collection for the full practical. Assignment 6 uses keyless Open-Meteo for weather.
