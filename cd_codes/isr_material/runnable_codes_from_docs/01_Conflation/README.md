# Assignment 1 ? Conflation and document representation

## How to run

`python -m pip install nltk`; download NLTK data once with `python -c "import nltk; nltk.download('punkt_tab'); nltk.download('stopwords'); nltk.download('wordnet')"`; then run `python practical1.py`. Edit `data/document.txt` to try another document. It tokenizes, removes stop words, stems and lemmatizes terms, then prints term frequencies. Notebook: `Practical.ipynb`.
