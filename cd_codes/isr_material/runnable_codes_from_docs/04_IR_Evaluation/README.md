# Assignment 4 ? Retrieval evaluation measures

## How to run

Install with `python -m pip install scikit-learn`, then run `python practical4.py`. It uses the same `cranfield/` and `TEST/query.txt` plus `TEST/RES/` layout named in the assignment. The included ten-document sample makes it runnable; replace it with the full Cranfield collection for the actual dataset. It ranks q1 and calculates Precision@10, Recall@10, F-measure, E-measure, DCG@10, IDCG@10 and NDCG@10 using the assignment formulas. Notebook: `Practical.ipynb`.
